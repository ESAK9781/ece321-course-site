1. Transistors as Switches and the Logic Inverter

Big idea. A logic gate uses transistors as switches. A switch is either open or a small resistor, and the output node is a capacitor, so the questions are always how far the transistor can pull the output and what that costs in power.

Understand it

The transistor as a switch. In cutoff the channel does not exist and the transistor is an open circuit. When the gate is driven hard, the transistor sits in triode with a small VDS, where the current k′(W/L)(VovvDS−12vDS2) is nearly linear in vDS, so the device acts as a resistor:

rDS,n=1kn′(W/L)(VGS−Vtn),rDS,p=1kp′(W/L)(VSG−|Vtp|)

A wider device or a larger overdrive gives a smaller resistance. Saturation is not used for switching.

Where does a switch stop pulling? Find the source. Take an NMOS that pulls a capacitive output Vo up from a supply, with its gate and drain at VDD (Figure 1.1). The source is the lower channel terminal, which is the output, so VGS=VDD−Vo. As Vo rises VGS shrinks, and the channel vanishes when VGS=Vtn. So the output can only reach

Vo,max=VDD−Vtn

For a PMOS pulling the output down the source is the output (the higher terminal) and VSG=Vo, so it stops at Vo,min=|Vtp|. With VDD=1.0V and |Vt|=0.35V that is 0.65V for the NMOS pull-up and 0.35V for the PMOS pull-down. The lesson: NMOS passes a good 0 and a weak 1; PMOS passes a good 1 and a weak 0. That is why CMOS uses NMOS to pull down and PMOS to pull up.

Three inverter designs. A resistor-load inverter has RD from VDD to the output and an NMOS to ground. With the input high the NMOS and RD form a divider, so the output low level is VOL=VDDrDS/(RD+rDS) ‡ voltage divider: not on sheet, which is small but never zero, and a static current VDD/(RD+rDS) ‡ Ohm’s law: not on sheet flows for as long as the input stays high. Switching is also lopsided: the output rises through RD but falls through rDS. Making RD large helps VOL but costs area and speed. Replacing RD by a saturated NMOS saves area but degrades the high level. The CMOS inverter (Figure 1.2) replaces the load by a PMOS driven by the same input, so in each steady state one device is off, there is no static path, and both levels reach the rails.

Where CMOS power goes. Charging the output capacitor from 0 to VDD draws charge CoVDD from the supply at voltage VDD, so the supply delivers E=CoVDD2 ‡ supply energy: not on sheet. Half of that is stored on the capacitor (12CoVDD2) and half is lost as heat in the PMOS, whatever its resistance. When the output falls, the stored half is dissipated in the NMOS and the supply gives nothing. One full cycle therefore costs CoVDD2, and at frequency f

P=CoVDD2f

For Co=5fF, VDD=1.0V and f=500MHz that is 5fJ per cycle and 2.5µW. Power is independent of the transistor resistance and scales with VDD2, which is why lowering the supply is the strongest power lever (dropping to 0.8V gives 0.64× the power).

Know these

  • rDS=1/[k′(W/L)(VGS−Vt)] in triode; cutoff is open.
  • NMOS pull-up reaches VDD−Vtn; PMOS pull-down reaches |Vtp|. NMOS pulls down well, PMOS pulls up well.
  • Resistor-load, input high: VOL=VDDrDS/(RD+rDS), static current VDD/(RD+rDS)‡ divider, Ohm: not on sheet.
  • CMOS: no static power; energy per cycle CoVDD2; P=CoVDD2f.

Method

  1. Find the source of the device (lower terminal for NMOS, higher for PMOS).
  2. Write VGS (or VSG) in terms of Vo and find where it equals the threshold.
  3. For a resistive load, use a voltage divider; for CMOS power, use CoVDD2f.

2. Pull-Up and Pull-Down Networks

Big idea. A static CMOS gate pairs a network of PMOS devices to VDD with a network of NMOS devices to ground, driven by the same inputs, so that for every input combination exactly one network conducts. Reading or building a gate comes down to two rules: series is AND, parallel is OR.

Understand it

The structure. The pull-up network (PUN) connects VDD to the output Y through PMOS devices; the pull-down network (PDN) connects Y to ground through NMOS devices. They must be complementary: if both conducted there would be a path from VDD to ground, and if neither did the output would float. In the simplified symbols a bubble on a gate marks a PMOS.

Switches as logic. An NMOS conducts when its gate is high, so a path of NMOS devices in series conducts only if all inputs are high (AND), and NMOS devices in parallel conduct if any input is high (OR). A PMOS conducts when its gate is low, so series PMOS conduct only if all inputs are low and parallel PMOS if any input is low.

Reading a gate. Write when the PDN conducts, fPDN, using series for AND and parallel for OR. Whenever the PDN conducts it connects Y to ground, so Y=fPDN‾. The PUN must give the same function; check it by remembering each PMOS wants a low input, so inputs enter complemented, and apply DeMorgan, AB‾=A‾+B‾ and A+B‾=A‾B‾.

Building a gate. Start from the output expression. The PDN conducts when Y‾=1, so write Y‾ as a sum of products and use NMOS devices: each product is a series string and the sum puts the strings in parallel. For the PUN push the bar through Y with DeMorgan until bars sit only on single inputs, then build with PMOS the same way; the result is the dual of the PDN (series and parallel swapped). From a truth table, write Y‾ as a sum of minterms (rows where Y=0) for the PDN and Y as a sum of minterms (rows where Y=1) for the PUN. An input needed in complemented form needs an inverter (2 transistors). An N-input gate uses 2N transistors, plus 2 per inverter.

Know these

  • NMOS on for high, PMOS on for low; series = AND, parallel = OR.
  • Y=fPDN‾; the PUN is the dual of the PDN with complemented inputs.
  • DeMorgan: AB‾=A‾+B‾, A+B‾=A‾B‾. Transistor count 2N plus inverters.

Method

  1. Analyze: write fPDN, then Y=fPDN‾; confirm with the PUN or a truth table.
  2. Synthesize: NMOS PDN from Y‾; DeMorgan on Y, then a PMOS PUN of dual structure.
  3. From a truth table: minterms of Y‾ for the PDN and of Y for the PUN.

3. Noise Margins and the CMOS VTC

Big idea. Noise pushes real voltages around, yet a gate must still read the right logic value. The noise margins measure how much noise a signal can take before the next gate misreads it, and they come straight from the shape of the inverter’s voltage transfer characteristic (VTC).

Understand it

Why we need margins. A digital signal is a voltage that we interpret as 0 or 1. Noise from neighboring wires or the supply adds to it. A gate’s output is guaranteed only to lie at or beyond VOL (for a 0) or VOH (for a 1); the next gate promises to read any input at or below VIL as a 0 and at or above VIH as a 1. The gaps between what is delivered and what is accepted are the margins:

NML=VIL−VOL,NMH=VOH−VIH

For CMOS the output swings fully to the rails, so VOH=VDD and VOL=0. All the work is in finding VIL and VIH.

Reading the VTC. The VTC plots the output against the input when everything has settled. At the left the NMOS is off and the PMOS holds the output at VDD; at the right the roles reverse and the output sits at 0. In between the output falls steeply, and that steep part is where the gate actually switches. Figure 3.1 marks the four corner points and the two input thresholds.

Which devices are on where. The mode of each transistor follows from its own terminal voltages: VGSN=VIN and VDSN=VOUT for the NMOS, VSGP=VDD−VIN and VSDP=VDD−VOUT for the PMOS. An NMOS is off below Vtn and saturated while VOUT>VIN−Vtn; a PMOS is off above VDD−|Vtp| and saturated while VOUT<VIN+|Vtp|.

Why slope −1 defines the thresholds. Near the rails the slope is small, so an input disturbance barely moves the output. Once the slope magnitude exceeds 1 the gate is amplifying: a small input change makes a larger output change, which means the gate has started switching. VIL is the input where the slope first reaches −1 on the low side, and VIH is where it returns to −1 on the high side. Inputs below VIL are safely a 0, inputs above VIH safely a 1, and in between the gate is not guaranteed to decide correctly.

The switching threshold VM. VM is the input at which the output equals the input, in the middle of the steep segment. Both devices are saturated there and carry the same current, so 12Kn(VM−Vtn)2=12Kp(VDD−VM−|Vtp|)2. Taking square roots and writing r=Kp/Kn gives

VM=Vtn+r(VDD−|Vtp|)1+r

If the devices are matched (Kn=Kp, so r=1, and Vtn=|Vtp|) this is VDD/2. A stronger PMOS (r>1) pulls the threshold up; a weaker one pulls it down.

The matched inverter. For the matched case, equating the currents at the unity-gain point (NMOS triode, PMOS saturated) and requiring slope −1 gives VIH, and symmetry gives VIL=VDD−VIH:

VIH=18(5VDD−2Vt),VIL=18(3VDD+2Vt)

For VDD=1.0V and Vt=0.35V these are 0.5375 and 0.4625V, so both margins are 0.4625V, about 93% of the ideal VDD/2.

Matching in silicon, and what it costs. Electrons are more mobile than holes (μn/μp is typically 2 to 5), so equal strength needs (W/L)p=(μn/μp)(W/L)n. A PMOS that wide costs area and adds capacitance, which slows the gate, so designers often use a narrower PMOS. The VTC then slides: VM moves (only slightly, because r appears in both numerator and denominator), and the margins shift by about the same amount. If ΔVM=VM−VDD/2, then NML changes by about +ΔVM and NMH by about −ΔVM. A modest margin loss often buys a large area saving.

Know these

  • CMOS: VOH=VDD, VOL=0; NML=VIL−VOL, NMH=VOH−VIH.
  • Matched: VIH=18(5VDD−2Vt), VIL=18(3VDD+2Vt), VM=VDD/2.
  • Unmatched: r=Kp/Kn, VM=Vtn+r(VDD−|Vtp|)1+r; margins shift by ±ΔVM.
  • To match: (W/L)p=(μn/μp)(W/L)n. Order check: VOL<VIL<VM<VIH<VOH, margins positive.

Method

  1. Matched inverter: put VDD and Vt into the two formulas, then subtract from the rails.
  2. Unmatched inverter: compute r from Kp/Kn (include widths and mobilities), then VM, then ΔVM.
  3. Shift the matched margins by ±ΔVM for an estimate; if levels are measured, use the definitions directly.

4. Propagation Delay

Big idea. A gate output is a capacitor that one transistor must charge or discharge, and that takes time. The delay is how late the output edge arrives after the input edge, and it grows with the capacitance and shrinks with the transistor’s drive.

Understand it

What limits the speed. The output node carries a capacitance C: the next gates’ inputs, the wire, and the driver’s own parasitics. To move the output by ΔV the transistor must move charge CΔV, and a current i delivers it in time Δt≈CΔV/i. So delay grows with C and falls as the transistor gets stronger. Everything below is a careful version of this one idea.

What we measure. Take VOL and VOH as the levels and mark the 10%, 50% and 90% points of each edge. A propagation delay runs from the 50% point of the input edge to the 50% point of the output edge. Because an inverter inverts, a rising input gives a falling output, written tPHL (the NMOS is doing the work), and a falling input gives a rising output, tPLH (the PMOS). A transition time is different: it is the 10% to 90% duration of a single edge (tTHL for a falling output). The single figure used to compare gates is tP=12(tPHL+tPLH). From a simulation you simply subtract: for example an input crossing 50% at 20.0ps and the output at 38.0ps gives tPHL=18.0ps.

Method 1: average current. The output must move through half its swing, so the charge is CVDD/2. The transistor current is not constant: it starts in saturation and ends in triode. Dividing the charge by the average current over that half swing gives

tPHL=anCKnVDD,tPLH=apCKpVDD,a=274−3VtVDD+(VtVDD)2

Here K=k′(W/L), and ap uses |Vtp|. The factor a packages the saturation and triode parts and normally lies between 1 and 3. Notice the shape of the formula: delay ∝C, ∝1/K (wider means faster) and ∝1/VDD (and a also grows as VDD falls). With matched devices the two delays are equal.

Method 2: equivalent resistance. Treat the on-transistor as a resistor and the output as an RC circuit. A capacitor charging from an initial to a final value follows vc=FV−(FV−IV)e−t/RC, and it reaches the 50% level when e−t/RC=12, that is t=RCln2:‡ charging law: not on sheet

tPHL=0.693RNC,tPLH=0.693RPC

The resistance of a reference transistor (Reff at Weff/Leff) comes from simulation of the real technology. Resistance is proportional to L/W, so for the actual device R=Reff(Weff/Leff)/(W/L): twice the width, half the resistance.

The load capacitance. Add the driver’s internal capacitance and the external load. Gate-drain capacitances count twice (the Miller effect: when the output moves by VDD the input moves the other way by VDD, so the voltage across them changes by 2VDD):

CINT=2Cgd2+2Cgd1+Cdb2+Cdb1,CEXT=(Cwire+Cg4+Cg3)×Fan\_Out

Which method when. Method 1 is built from device parameters and contains VDD, so it is the only one that can predict what happens when the supply changes. Method 2 uses simulated resistances measured at one supply, which usually makes it closer to a real deep-submicron process, but it cannot be re-used at a different VDD. Lowering VDD saves power but slows the gate.

Know these

  • tP=12(tPHL+tPLH); delays use 50% points, transition times use 10% to 90%.
  • Method 1: t=aC/(KVDD) with K=k′(W/L). Method 2: t=0.693RC with R=Reff(Weff/Leff)/(W/L).
  • C=CINT+CEXT with the Miller factor 2 on the gate-drain terms.

Method

  1. Decide the direction: falling output means NMOS and tPHL; rising output means PMOS and tPLH.
  2. Assemble the total load C.
  3. Apply the method asked for, then average. Any change of VDD needs Method 1.

Quiz-Day Checklist

  • Switches. NMOS: strong 0, weak 1 (VDD−Vtn). PMOS: strong 1, weak 0 (|Vtp|). CMOS has no static power; P=CoVDD2f.
  • Networks. Series is AND, parallel is OR; Y=fPDN‾; PUN is the dual with complemented inputs; 2N transistors.
  • Noise margins. VOH=VDD, VOL=0. Matched: VIH=18(5VDD−2Vt), VIL=18(3VDD+2Vt). Unmatched: r, then VM, then shift by ±ΔVM.
