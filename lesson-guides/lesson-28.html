Lesson 28: Transistor-Level Digital Design, Pull-Up and Pull-Down Networks, and the Logic Inverter

28-1

Transistor-Level Digital Design: Chaps 16, 17, 18

LOGIC

Q. What is the iron-triangle of digital design

  • gates
  • latches
  • flip-flops
  • memory: SRAM, DRAM?
Expansion note: why the three goals pull against each other

A designer wants the circuit to burn little power, to switch quickly and to take little chip area, and improving one usually costs another. Bigger transistors have lower on-resistance and so charge a load faster, but they take more area and carry more capacitance, which raises the power spent each time the output changes. The same trade-off shows up in every circuit listed on the left: gates, latches, flip-flops and memory cells (SRAM and DRAM), which are all built from the same transistor switches.

Device Review: In order to build gates we will need to use devices as switches (cutoff to triode)

Expansion note: why cutoff and triode are the two switch states

In cutoff (vGS<Vtn) there is no channel, so the drain current is zero and the transistor acts like an open switch. In triode with a large overdrive the channel is a small resistance rDS between drain and source, which acts like a closed switch. Saturation, where the transistor behaves as a current source, is not used for digital switching because the output would never be forced fully to a rail.

ON: VGS>Vtn   Tri: VDS≤Vov

When ON: rDS = 1knVov = 1kn′(W/L)(VGS−Vtn)   kn′=μnCox

Expansion note: where the ON resistance comes from

In triode the NMOS current is

iD=kn′WL[(vGS−Vtn)vDS−12vDS2]

For a small vDS the squared term is negligible, so iD≈kn′(W/L)VovvDS, and the ratio vDS/iD is the resistance of the switch:

rDS=vDSiD=1kn′(W/L)Vov=1knVov,kn=kn′WL

A wider device (larger W/L) or a larger gate drive (larger Vov=VGS−Vtn) gives a smaller resistance. The factor kn′=μnCox is set by the process.

(∗) The PMOS always has its S at the highest voltage and iD flows from S to D

Expansion note: how to tell the PMOS source from its drain

For a PMOS the source is whichever of the two channel terminals is at the higher voltage, and the current flows through the channel from source to drain. That is why the PMOS equations are written with VSG and VSD: both are positive when the device conducts. Because Vtp is negative, the turn-on condition is written with its magnitude, VSG>|Vtp|.

(∗) For logic gates, we want the output to pull up to VDD for a logical "1" and pull down to gnd for a logical "0"

Expansion note: why the two networks are complementary

The pull-up network (PUN) connects the output to VDD and the pull-down network (PDN) connects it to ground. For every combination of inputs exactly one of them should conduct. If neither does, the output floats and holds no definite logic level. If both do, current flows straight from VDD to ground and the output sits at an undefined voltage in between.

(∗) The output of gates are other gates and looking into a FET we see a gate capacitance so that's what we assume as an output

Expansion note: why every output is modelled as a capacitor

A MOSFET gate is insulated from the channel, so the next gate draws no DC current and looks like a small capacitor to ground. The load on any gate output is therefore the gate capacitance of the gates it drives (plus wiring), drawn as Co. The speed of a gate depends on how quickly its pull-up or pull-down network can charge or discharge this capacitor.

Expansion note: why an NMOS pull-up stops short of V_DD

Both the gate and the drain sit at VDD, and the source is the output node. The output rises only while the NMOS is on, which needs VGS=VDD−Vo≥Vtn. As Vo climbs, VGS shrinks, and when Vo reaches VDD−Vtn the gate-source voltage has fallen to the threshold and the channel disappears. The capacitor stops charging a threshold voltage below the supply, which is the degraded high level.

Expansion note: why a PMOS pull-down stops above 0 V

The source is the output node and the gate is at ground, so VSG=Vo. The PMOS conducts only while Vo≥|Vtp|. As the capacitor discharges through it, Vo falls, and when it reaches |Vtp| the channel closes and the discharge stops. The output is stuck one threshold magnitude above ground, a degraded low level. This is the mirror image of the NMOS pull-up problem.

(∗) We make 4 key observations

  1. Only PMOS in the PUN
  2. Only NMOS in the PDN
  3. VG = VDD turns the NMOS on
  4. VG = 0 turns the PMOS on
Expansion note: how the four observations follow from the pass-level results

An NMOS passes a good 0 (it discharges the output all the way to ground) but a degraded 1, so it belongs in the pull-down network. A PMOS passes a good 1 but a degraded 0, so it belongs in the pull-up network. Observations 3 and 4 say which gate voltage switches each device on, which is what lets one input signal control both networks.

Option #1: A common-source NMOS topology

  • If VGS = 0 then NMOS = OFF & Co charges up to VDD through RD, at pt D
  • If VGS = VDD then NMOS = ON & Co discharges to pt C through rds,n. VDS ≠ 0 and iD ≠ 0 → we have static power dissipation when logical "1" applied
Expansion note: how to read the points D, A, B and C on the curve

The curve is the output voltage VDS against the input VGS. From VGS=0 to the threshold (D to A) the NMOS is cut off, no current flows through RD, and the output sits at VDD. Above the threshold the NMOS conducts in saturation (A to B) and the output falls steeply as the drain current drops voltage across RD. At B the transistor enters triode, and as the input rises toward VDD it ends at C, with the output at a small but nonzero value set by RD and rds,n.

Expansion note: why the output at C is not 0 V and the current never stops

With the NMOS on, RD and rds,n form a voltage divider between VDD and ground, so the low output level is approximately

VOL≈VDDrds,nRD+rds,n≠0

and the same path carries the static current I=VDD/(RD+rds,n) for as long as the input stays high. That current is dissipated as heat in the circuit even though nothing is switching, which is static power dissipation.

Four observations:

  1. High static dissipation
  2. Asymmetric switching L→H vs H→L   RD>rds,n
  3. VOL ≠ 0
  4. RD physically big for IL†
Expansion note: why the switching is asymmetric

A low-to-high change charges Co through RD, with time constant RDCo. A high-to-low change discharges it through rds,n, with time constant rds,nCo. Because RD must be much larger than rds,n (otherwise VOL would be large), the rising edge is much slower than the falling edge.

Expansion note: why R_D has to be physically large

To keep VOL small and the static current low, RD must be much larger than rds,n. A large resistance built on a chip takes a lot of silicon area, so the resistor costs area, which works against the area corner of the iron triangle.

Expansion note: why the load NMOS is always in saturation

Its gate and drain are joined, so VGD=0, which is below Vtn. A transistor is saturated when VGD<Vtn (the drain end of the channel is pinched off), so this one never enters triode: it acts as a resistor whose value is large because a saturated transistor's small-signal resistance is large. It replaces RD but has the same weakness as the NMOS pull-up of page 28-4: the high output is limited to VDD−Vtn, a degraded voltage level (DVL). Its advantage is that a transistor takes far less area than a big resistor.

Option 3: CMOS complementary → both pmos & nmos

"1" Vin=VDD   NMOS ON   PMOS OFF

VIN = 0 V   NMOS OFF   PMOS ON

Expansion note: why the CMOS inverter fixes the earlier problems

With Vin=VDD the PMOS gate-source voltage is 0, so the PMOS is off, while the NMOS is on and pulls the output to 0 V through rds,n. With Vin=0 the NMOS is off and the PMOS is on, pulling the output to VDD through rds,p. In each state one device is on and the other is off, so there is no steady path from VDD to ground, and the output reaches the full rail value (no degraded level). The on-device can be made as strong as needed for fast switching, with no big resistor.

Expansion note: how the operating point is found from the two curves

The two transistors are in series, so they carry the same current, iDp=iDn, and the output voltage is the NMOS drain-source voltage, VOUT=vDS,n. The operating point is where the two current curves, plotted against VOUT, cross. With the input high the PMOS curve is essentially zero everywhere (it is off), so the crossing is at zero current, which is at VOUT=0 on the NMOS curve. The power drawn from the supply is VDDi=0.

Expansion note: why the PMOS curve is plotted against V_OUT in the low-input case

The PMOS drain-source voltage is VSDp=VDD−VOUT, so against VOUT the PMOS current is largest at VOUT=0 (large VSD, saturation) and falls to zero at VOUT=VDD, where VSD=0. The NMOS is off, so its curve stays at zero. The curves meet only at VOUT=VDD with i=0, so the output is a full VDD and again no power is dissipated.

28-9

(∗) CMOS has no static dissipation

Expansion note: why CMOS has no static dissipation

In each steady logic state one of the two series transistors is off, so there is no conducting path from VDD to ground and the supply current is zero. (Small leakage currents in the off device are ignored in these notes.) The output is held at the rail with no current needed.

Q. What about when changing state?

Vin = 0 V   L→H

Vin = VDD   H→L

Expansion note: reading the two transitions and the time δt = 5RC

When the input goes low the PMOS turns on and Co charges toward VDD through rds,p. When it goes high the NMOS turns on and Co discharges toward 0 through rds,n. Either way the output follows an exponential with time constant τ=RCo, where R is the on-resistance of the conducting device. After one time constant it has covered about 63% of the change, and after five it has covered more than 99%, so the output is considered settled after δt=5RC.

(∗) Power dissipation happens when changing state. For a chip, you may have millions of these switching a millions times a second!

→ we have to care!

Expansion note: why a transition costs power

Charging Co from 0 to VDD takes a charge CoVDD from the supply, which is an energy CoVDD2. Half of it ends up stored on the capacitor (12CoVDD2) and the other half is dissipated as heat in the resistance of the conducting transistor, whatever its value. The stored half is dissipated in the NMOS when the output is discharged. With f transitions per second, a gate dissipates on the order of CoVDD2f, and a chip with millions of gates switching millions of times a second adds up to a large total.

Appendix

A. Problem Types in This Notetaker and How to Solve Them

A1. Deciding whether a MOSFET is on, off or in triode, and finding its switch resistance

Recognize it

You know the gate, source and drain voltages of an NMOS or PMOS (and its threshold) and must say whether it conducts, and if so what resistance it presents as a switch.

Method

  1. Identify source and drain. NMOS: the source is the lower-voltage channel terminal. PMOS: the source is the higher-voltage channel terminal.
  2. Compute the gate-source voltage: VGS for an NMOS, VSG for a PMOS.
  3. Compare with the threshold. NMOS on if VGS>Vtn; PMOS on if VSG>|Vtp|; otherwise it is in cutoff and looks like an open circuit.
  4. If it is on, find the region: triode if VDS≤Vov (NMOS) or VSD≤|Vov| (PMOS), saturation otherwise.
  5. For a switch in triode, the on-resistance is rDS=1/(knVov) with kn=kn′(W/L) and Vov=VGS−Vtn (PMOS: 1/(kp|Vov|), Vov=VSG−|Vtp|).

Checks

  • A logic input at a rail gives VGS (or VSG) equal to VDD or 0, so the device is clearly on or clearly off.
  • The threshold is usually between one fifth and one third of VDD (page 28-3), so VDD>Vtn holds comfortably.

Variants

  • If given μnCox instead of kn′, use kn′=μnCox.
  • A wider device (larger W/L) has a smaller rDS.

Common mistakes

  • Using VGS for a PMOS, or forgetting the absolute value of Vtp (which is negative).
  • Treating the on-resistance as valid in saturation; the formula holds for the small-VDS triode region.

Worked in these notes: the device review, pp. 28-1 to 28-2, and the on/off cases on pp. 28-3 to 28-5.

A2. Finding the voltage a transistor can pass onto a load capacitor (pass level)

Recognize it

One transistor connects a rail or a logic level to the output capacitor Co, and you are asked what voltage the output can reach. The question may read "what if we move the NMOS to the pull-up network?" or "what if we move the PMOS to the pull-down network?"

Method

  1. Write the three voltages VG, VD and VS, with the output node as the source in both cases.
  2. Write the turn-on condition in terms of Vo: NMOS VGS=VDD−Vo≥Vtn; PMOS VSG=Vo−0≥|Vtp|.
  3. Solve for the output limit: Vo,max=VDD−Vtn (NMOS) or Vo,min=|Vtp| (PMOS).
  4. If the limit is short of the rail, the level is degraded and the device cannot pass that logic level by itself.

Checks

  • An NMOS pulling down (source at ground) and a PMOS pulling up (source at VDD) reach the rails fully; the output ends at 0 or VDD.
  • Illustration with made-up numbers: VDD = 5 V, Vtn = 1 V gives Vo,max = 4 V.

Variants

  • Option 2 on page 28-7 is the same NMOS pull-up with its gate tied to its drain; the limit is again VDD−Vtn (DVL).

Common mistakes

  • Assuming the output reaches the supply because the gate is at VDD; the gate-source voltage shrinks as the output rises.
  • Mixing up which terminal is the source when the roles of the terminals change.

Worked in these notes: pp. 28-4 and 28-5.

A3. Choosing NMOS or PMOS for the pull-up and pull-down networks

Recognize it

You must decide which device type goes in the pull-up network (between VDD and the output) and which in the pull-down network (between the output and ground), and which input level turns each on.

Method

  1. The pull-up network must pass a good "1", so it contains only PMOS devices.
  2. The pull-down network must pass a good "0", so it contains only NMOS devices.
  3. An NMOS turns on when its gate is at VDD ("1"); a PMOS turns on when its gate is at 0 ("0").
  4. Arrange them so that exactly one network conducts for each input pattern.

Checks

  • For every input combination the output is connected to one rail and not the other.

Variants

  • With several inputs the networks become series and parallel combinations of devices (next lesson); the device types stay fixed.

Common mistakes

  • Putting an NMOS in the pull-up network because it also switches on with a high gate.

Worked in these notes: pp. 28-2 to 28-5.

A4. Evaluating a candidate logic inverter (resistor load, NMOS load, CMOS)

Recognize it

You are given an inverter topology and asked about its static power, its low output level, its switching symmetry or its area, and which option is best.

Method

  1. For each logic input, decide which transistors are on and draw the equivalent circuit (switch resistances and Co).
  2. Look for a steady path from VDD to ground. If one exists (Option 1 with the input high), there is static current and static power.
  3. Find the low output level. With a resistor load it is approximately VDDrds,n/(RD+rds,n), which is not 0.
  4. Compare the charging path with the discharging path for symmetry: RDCo against rds,nCo.
  5. Check the high level: an NMOS load limits it to VDD−Vtn.
  6. Judge the area: a resistor load needs a physically large RD.

Checks

  • Only the CMOS inverter has full rail-to-rail levels, no static path and symmetric strong pull-up and pull-down.

Variants

  • Option 2 replaces RD by a saturated NMOS: smaller area, but the high level is degraded.

Common mistakes

  • Saying the resistor-load inverter has no static power because its output is low; the power is dissipated when the input is high.

Worked in these notes: Options 1 to 3, pp. 28-5 to 28-7.

A5. Finding the operating point and static power of a CMOS inverter

Recognize it

The input is held at 0 or VDD and you must find the output voltage, the current and the power.

Method

  1. With Vin=VDD: VSGp=0<|Vtp| so the PMOS is off; VGSn=VDD>Vtn so the NMOS is on.
  2. With Vin=0: VSGp=VDD so the PMOS is on; VGSn=0 so the NMOS is off.
  3. The devices are in series, so iDp=iDn; the output is VOUT=vDS,n=VDD−VSDp.
  4. Plot both currents against VOUT; the operating point is where they intersect.
  5. Read the current there (i=0) and the output (0 or VDD); the power is VDDi=0 W.

Checks

  • The off device carries no current, so the on device carries none either; the on device then has VDS=0.

Variants

  • Mid-transition (input near the switching region) both devices conduct, which is treated in the next lessons.

Common mistakes

  • Plotting the PMOS curve against VSD instead of VOUT when overlaying it on the NMOS curve.

Worked in these notes: pp. 28-8 and 28-9.

A6. Describing a switching transition (charge and discharge through a switch resistance)

Recognize it

The input changes from low to high or high to low, and you must say which transistor conducts, what the output does, and how long it takes.

Method

  1. Low-to-high output (input goes to 0): the PMOS is on, and Co charges through rds,p toward VDD.
  2. High-to-low output (input goes to VDD): the NMOS is on, and Co discharges through rds,n toward 0.
  3. The time constant is τ=RCo with R the on-resistance of the conducting device.
  4. The transition time is δt=5RC (about five time constants).

Checks

  • The output waveform is an exponential approaching the rail, not a straight line.

Variants

  • If rds,n≠rds,p the two edges take different times.

Common mistakes

  • Concluding from the zero static power that CMOS dissipates no power: power is dissipated while the output changes.

Worked in these notes: p. 28-9.
