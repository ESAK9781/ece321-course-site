Examples Using MOSFET Models

Ex. 1

Determine RD and RS so ID = [handout value]† mA and VD = [handout value]† V. The device has Vt = [handout value]† V, μnCox = [handout value]† μA/V², L = [handout value]† μm, and W = [handout value]† μm. Neglect channel-length modulation → λ = 0.

STEP 1: Find the required resistor from its voltage drop: R = ΔV/I. The target current and the supply/load drops needed to evaluate a numerical resistance are handout values.

Expansion note: why the resistor uses the current target

In the DC series path, the drain and source resistors carry the same channel current. Apply Ohm’s law to the drop across each resistor; use the actual rail-to-node voltage difference, not the full supply unless the node is at ground.

STEP 2: Find the transistor operating point. With the gate grounded, VGS = −VS. Compare this with the threshold voltage before using the saturation model.

STEP 3: Use the drain-current relation to find VGS: ID=12μnCoxWL(VGS−Vt)2. For the shown 0.2 mA example, substitution still depends on the omitted process and geometry values; no numeric gate voltage is determined by this copy.

Expansion note: what the square-law model assumes

This long-channel model applies in saturation and neglects channel-length modulation, as the notes specify. Its overdrive is VOV = VGS − Vt; a valid NMOS on-state requires positive overdrive.

STEP 4: Find the drain voltage from the supply and resistor drop, VD = VDD − IDRD.

STEP 5: Find RS using IS = ID and the source-resistor voltage drop.

Ex. 2

Derive the I–V characteristic for a diode-connected transistor in terms of kn′(W/L) and Vtn.

STEP 1: Determine the MOS mode. With gate and drain connected, VG = VD, so VGS = VDS. If the device is on, VGS > Vtn; consequently VDS > VGS − Vtn, satisfying the saturation condition.

Expansion note: why a diode-connected NMOS is in saturation

Saturation requires VDS ≥ VGS − Vtn. Since the connection makes VDS = VGS, the inequality holds whenever the transistor is on.

Thus iD=12kn(VGS−Vtn)2,kn=kn′WL. For a two-terminal diode connection, use the applied terminal voltage for VGS.

10-3

STEP 2: From the circuit, the applied voltage and current are related by the diode-connected device, giving the same saturation square law in the independent variable set by the circuit.

Ex. 3

Find all currents and node voltages assuming Vtn = [handout value]† V and kn′ = [handout value]† μA/V².

STEP 1: Find VG using the divider. Since gate current is approximately zero, the two divider resistors set the gate voltage.

STEP 2: Use the source current to solve for ID. Write VGS = VG − VS and VS = IDRS, then solve the square-law relation. Candidate solutions must be checked against the assumed region.

Expansion note: why the source resistor creates feedback

When drain current rises, the source voltage rises through RS. That reduces VGS and opposes the original current increase. Algebra may yield more than one root; only roots consistent with the MOS operating-region inequalities are physical.

10-4

STEP 3: Check each solution against the mode. For saturation, check VDS ≥ VGS − Vtn, equivalently VGD ≤ Vtn. Reject any root that violates its assumed region or gives an impossible current/voltage.

Expansion note: how to reject an extraneous root

Substitution into a squared equation can produce a mathematical root with the wrong sign of overdrive. Recompute all node voltages for each candidate, then test threshold and region inequalities before accepting it.

Ex. 4

Choose RG1, RG2, and RD to set the MOSFET with ID = [handout value]† mA and VD = [handout value]† V for a device with Vtn = [handout value]† V and kn′ = [handout value]† μA/V². What is the largest RD to stay in saturation?

STEP 1: Identify VGS. Assuming saturation, ID = ½kn(VGS − Vtn)², so VOV = √(2ID/kn) and VGS = Vtn + VOV.

STEP 2: Find VG from VG = VS + VGS, where VS = IDRS.

STEP 3: Choose divider resistors such that VG = VDDRG2/(RG1 + RG2). Many resistor pairs give the same ratio; choose a practical divider current large enough relative to gate leakage.

10-6

STEP 4: Determine RD from the drain drop: RD = (VDD − VD)/ID.

STEP 5: At the edge of saturation, VDS = VOV. Because VD = VDD − IDRD, maximum drain resistance is RD,max=VDD−VS−VOVID. A lower drain voltage would put the device in triode at the specified current.

Ex. 5

Given matched NMOS and PMOS devices with kn′ = kp′ = [handout value]† μA/V², Vtn = |Vtp| = [handout value]† V, and λ = 0, find IDN, IDP, and VO for VI = 0 V, +2.5 V, −2.5 V.

10-7

In saturation, IDN=12kn(VGS−Vtn)2,IDP=12kp(VSG−|Vtp|)2. These currents and the load current must satisfy KCL: Iload = IDN − IDP, with sign determined by the chosen current directions. For each input, first identify which devices conduct, then solve the output-node current balance.

Determine VGD for each device and verify the saturation condition for any transistor assumed saturated.

Expansion note: why matched devices do not always share equal current

Matching means equal process and geometry factors under the stated assumptions. Their gate-source overdrives can differ, and a load attached to the output supplies or sinks current. KCL, not matching alone, determines the node current balance.

For VI = +2.5 V, the PMOS has VSG below |Vtp| and is off. Redraw the remaining NMOS path. Use the output and source node voltages to check whether the NMOS is in saturation or triode.

For triode operation, IDN=kn[(VGS−Vtn)VDS−12VDS2]. Solve with the load relation and verify VDS < VGS − Vtn.

Appendix

A. Solving MOSFET bias and region problems

Start with gate-bias constraints and identify the unknown node voltages. Express VGS and VDS from node voltages, assume a region, apply its current equation, solve, then check the region inequalities and current direction.

B. Topics in these notes

NMOS square-law saturation; channel-length modulation neglected (λ = 0); diode-connected MOSFETs; gate-divider bias; source degeneration; operating-region verification; NMOS/PMOS complementary stages; KCL with a resistive load; triode operation.
