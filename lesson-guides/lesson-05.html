Expansion note: how the notation separates bias from signal

Uppercase quantities such as VD and ID denote the DC operating point; lowercase vd(t) and id(t) denote small changes around it. The packet writes the input perturbation with a supply-style subscript on this line, then uses lowercase perturbations in the small-signal equations.

This is the small-signal approximation, and we characterize as shown next.

Expansion note: how linearization produces the diode resistance

Expand evd/VT ≈ 1 + vd/VT when |vd| ≪ VT. Subtracting the DC current ID leaves id = (ID/VT)vd. Thus the incremental conductance is ID/VT and the small-signal resistance is rd = VT/ID.

A. Problem Types in This Notetaker and How to Solve Them

A1. Analyze a diode circuit with an assumed ideal or constant-drop state

Recognize it. A source, resistor and diode are given and the model is specified. Method. (1) Assume the diode is on or off. (2) Replace an on ideal diode by a short, or a conducting constant-drop diode by its fixed drop; replace an off diode by an open. (3) Apply KVL/KCL and solve for the current and diode voltage. (4) Check consistency: on requires forward current; off requires a non-forward voltage and zero current. Checks and variants. If the assumed state fails its inequality, switch states and solve again. For the packet’s 5 V, 1 kΩ example, the ideal on-state gives 5 mA and 0 V; the 0.7 V model gives 4.3 mA and 0.7 V. Common mistakes. Using the source voltage as the diode voltage, skipping the state check, or assigning a forward drop to an off diode. Worked in these notes: page 5-1 and 5-2.

A2. Find a diode operating point with the exponential law and load line

Recognize it. A diode is in series with a source and resistor, and an accurate forward-bias model is requested. Method. Write iD = (V − vD)/R and iD = IS(evD/VT − 1); solve for their intersection by a numerical root method or graphically. In forward bias where vD ≫ VT, use the approximation iD ≈ ISevD/VT. Checks. The result must satisfy both equations and have the assumed forward polarity. Variants. If the numerical example lacks V, R or diode data, keep the equations symbolic. Common mistakes. Confusing the load line with the diode curve or taking ln of a dimensional current without forming a ratio. Worked in these notes: pages 5-3–5-7.

A3. Solve coupled equations with Gauss–Seidel iteration

Recognize it. A simultaneous linear system is rearranged so each unknown is expressed in terms of the others. Method. Choose starting guesses; compute the first updated variable from the latest available values, then immediately use it to compute the next variable. Repeat until successive values change by less than a chosen tolerance. Checks. Substitute the converged values into the original equations and verify residuals. Convergence depends on the system and update arrangement. Common mistakes. Using only prior-iteration values (that is Jacobi iteration), mixing iteration indices, or assuming every rearrangement converges. Worked in these notes: pages 5-5–5-7.

A4. Linearize a diode about its DC operating point

Recognize it. A small time-varying perturbation is superimposed on a forward DC bias, and the incremental response is needed. Method. Write vD(t) = VD + vd(t) and iD(t) = ID + id(t), then use a first-order expansion of the exponential for |vd| ≪ VT. The incremental resistance is rd = VT/ID. Checks. The perturbation must remain small compared with VT; otherwise the linear model is inaccurate. Common mistakes. Applying the linear model before finding the DC operating point or confusing lowercase perturbations with uppercase DC values. Worked in these notes: pages 5-7–5-8.
