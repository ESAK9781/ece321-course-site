Lesson 36: SR Latches, Cross-Coupled Inverters and Sizing the Write Transistors

36-1

Review SRAM READ

Assume Q= 1† Q‾= 0†

  1. ①
    Set φP= VDD†
    VB & VB‾ → VDD/2
  2. ②
    Set φP= 0†
  3. ③
    Set W= VDD†
    VQ‾ rises slightly†   VQ stays high†
  4. ④
    Set φS= VDD†
    Feedback: VB → VDD   VB‾ → 0
  5. ⑤
    Turn on column decoder†

(*) We limit† VQ‾ to not turn on† N2†

WaWn ≤ 1[1−(VtnVDD−Vtn)]2−1 which is less† Than 4 (3.69 for 65 nm)†

so access transistors must be no more than 3.7 times wider† than the NMOS transistors

Expansion note: what limiting VQ‾ means

If node Q‾ rises above the threshold of the NMOS of the other inverter (N2, whose gate is Q‾), N2 turns on and begins to pull Q down, which can flip the stored bit during a read. Keeping VQ‾<Vtn prevents that, and the sizing result bounds the access transistor against the pull-down transistor.

36-2

SRAM WRITE Operation: Assume Q From 1† to 0†

  1. STEP 1:
    To write a 0†, VB= 0†   VB‾= VDD†
  2. STEP 2:
    W= VDD†
  3. STEP 3:
    No sense amplifier or pre-charge† (both off)
  4. STEP 4:
    Need VQ → 0† & VQ‾ → VDD† and have at least one go below the inverter threshold VM (Vtn)†
  5. STEP 5:
    W= 0†
Expansion note: why a write is faster than a read

A write drives the bit lines hard from strong drivers, so they reach VDD and 0 immediately; the large bit-line capacitance does not have to be discharged through a small cell transistor. Only the small cell node Q must be pulled below the switching threshold, after which the latch's own regeneration finishes the change in roughly two inverter delays.

36-3

Transistor Sizing: WRITE

  • W= VDD† → A1 & A2 on†
  • Q= 1† → VQ= VDD†    Q‾= 0† → VQ‾= 0†
    → N_1† & P_1† on / off†    → N_2† & P_2† off / on†
  • need to pull Q down† and Q‾ up†
    If VQ >† Vt latch state will not change†

(*) Let's determine the transistor operating modes when VQ= Vt†. Recall,

NMOS triode† if VDS < VGS−Vtn

PMOS triode† if VSD < VSG−|Vtp|

Expansion note: why the pull-up fights the access transistor

To write a 0 the access transistor A2 pulls node Q toward the grounded bit line B. Against it, P2 (whose gate Q‾ is still low) pulls Q up toward VDD. The write succeeds only if A2 can drag Q below Vt against P2, which is the sizing condition derived on the next pages. The other half of the cell, pulling Q‾ up through A1 from the high B‾, cannot help because the read-sizing limit already prevents A1 from raising Q‾ above Vtn.

36-4

Mode for P2:

VS= VDD   VG= 0   VD= Vt ⇒ VSD= VDD−Vt   VSG= VDD

VSD ≥ VOV → saturation   (VOV=VDD−Vt)

IDP2=12μC(WL) [VDD −Vt]2

Mode for A2:

VS= 0   VG= VDD   VD= Vt ⇒ VDS= Vt   VGS= VDD

VDS < VOV → triode   (VOV=VDD−Vt)

IDA2=μC(WL) [(VDD−Vt)Vt−12Vt2]

Expansion note: why P2 sits at the edge of saturation

P2 has its source at VDD, its gate at 0 and its drain at Q=Vt. So VSG=VDD, VOV=VDD−|Vtp| and VSD=VDD−Vt. With |Vtp|=Vt the two are equal, so P2 is exactly at the edge of saturation and the saturation current equation applies. The access transistor A2 has a small VDS=Vt across it and is in triode.

Expansion note: the numbers and how the two limits combine

With μn/μp=3 and x=Vt/(VDD−Vt)=0.35/0.65=0.538: 1−(1−x)2=1−0.213=0.787, and 3×0.787=2.36. Equivalent form from the currents: 3×0.16625/0.21125=2.36. The read limit gave Wa≤3.69Wn and the write limit gives Wp≤2.36Wa, so the cell is designed from the inside out: choose Wn, then Wa up to 3.69Wn for a fast read, then Wp up to 2.36Wa. The text's Exercise 18.8 finds (W/L)p≤17.5 with (W/L)n=2 and (W/L)a=7.4, and a minimum-area cell with all widths at the 130 nm minimum.

Appendix

A. Problem Types in This Notetaker and How to Solve Them

A1. Sequencing an SRAM write

Recognize it

"Write a 0 into a cell storing a 1: what are B, B‾, W?" (p. 36-2).

Method

  1. Set the bit lines to the new value: VB=0, VB‾=VDD for a 0 (reverse for a 1).
  2. Raise W to VDD; sense amplifier and pre-charge stay off.
  3. A2 pulls Q down; A1 pulls Q‾ up; one node must pass the inverter threshold.
  4. Lower W to 0 once regeneration has taken over.

Checks

  • Opposite values on B and B‾.

Common mistakes

  • Leaving the pre-charge circuit on during the write.

Worked in these notes: p. 36-2.

A2. Maximum PMOS size for a successful write

Recognize it

Given VDD, Vt and μn/μp, find the largest Wp/Wa (pp. 36-3 to 36-6).

Method

  1. Require VQ≤Vt.
  2. P2: VSD=VDD−Vt equals VOV, so edge of saturation: IDP2=12μpCox(W/L)p(VDD−Vt)2.
  3. A2: triode with VDS=Vt: IDA2=μnCox(W/L)a[(VDD−Vt)Vt−12Vt2].
  4. Require IDP2≤IDA2 and solve: WpWa≤μnμp[1−(1−VtVDD−Vt)2].

Checks

  • VDD=1.0 V, Vt=0.35 V, μn/μp=3 gives 2.36.

Common mistakes

  • Using the triode equation for P2.
  • Forgetting μn/μp.

Worked in these notes: pp. 36-3 to 36-6.

A3. Sizing a whole SRAM cell

Recognize it

"Choose Wn, Wa, Wp for the cell" (p. 36-6).

Method

  1. Choose Wn (often the minimum width).
  2. Read limit: Wa≤Wn\{1[1−Vtn/(VDD−Vtn)]2−1\}.
  3. Write limit: Wp≤Waμnμp[1−(1−VtVDD−Vt)2].
  4. Pick widths at or below the limits; a larger Wa gives a faster read but a bigger cell.

Checks

  • 65 nm: Wp≤2.36Wa≤2.36(3.69)Wn.

Common mistakes

  • Applying the logic-gate worst-case-path method to the cell.

Worked in these notes: pp. 35-8, 36-1, 36-6.
