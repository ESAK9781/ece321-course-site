(*) Consider a set† operation

Expansion note: what the figure shows for the set operation

For a set, φ=S=VDD turns NP1 and NP2 on. Their series pair acts as the one transistor NP12 with its gate at VDD. On the other side R=0, so NP4 is off and NP34 is drawn with its gate at 0. The set pulse therefore pulls node Q‾ down against the PMOS P1.

At VQ‾=VDD/2 both transistors are in triode with the same voltage bracket, so the condition IDNP12≥IDP1 reduces to Kn′(W/L)NP12≥Kp′(W/L)P1. Since (W/L)NP12=12(W/L)NP1, this is 12Kn′(W/L)NP1≥Kp′(W/L)P1, which is the line above.

Q. How long must S† & φ† remain high to ensure switching?

Expansion note: reading the timing plot

The set pulse rises at the first dashed line. Node Q‾ then falls; the time to reach VDD/2 is tPHL (second dashed line), at which point the (P1,N1) inverter begins to flip and its output Q starts to rise. Q must then climb to VDD/2 so that the (P2,N2) inverter flips and the feedback loop closes; that takes tPLH (third dashed line). Only after that can the pulse end, so the pulse must last at least tPHL+tPLH.

The capacitor current changes from 380.3 µA at the start to 180 µA at the half-supply point. Approximating it by the average of the two end values is the average-current method of Lesson 31. The charge to move is CΔV=CVDD/2, so tPHL=C(VDD/2)/iC,ave.

Once Q‾ has fallen below VDD/2, the (P1,N1) inverter output Q rises to VDD/2 by the pull-up current of P1 alone, which is an ordinary inverter low-to-high transition. The Lesson 31 result tPLH=apC/(Kp′(W/L)pVDD) applies directly with C=10 fF, ap=2.43 and (W/L)p=390/65=6.

Computer Memory

Q. Why do we care? Most of chip area† · Most of chip power† · Biggest performance bottleneck†

Q. How do we think about memory

Expansion note: how to read the memory pyramid

Moving down the pyramid, each level holds more data but takes longer to reach and costs less per bit. The top level is a few kilobytes (registers and the first-level cache, built from fast SRAM) reached in under a nanosecond; main memory is gigabytes of DRAM at 10 to 30 ns; storage is terabytes at about a millisecond. The labels inside the levels are the usual technology for each size and are not printed in the notes.

34-7

ex. How do we architect 1 MB of memory?

1 MB = 220 Bytes × 8 bits/Byte = 223 bits

Q. How do we arrange this?

(*) We desire to make this more square† so we fold† it

Expansion note: why 1 MB is 223 bits

One megabyte here means 220 bytes (about a million) and each byte is 8 bits =23, so there are 220·23=223 bits. Laid out as one byte per row the array would be 220 rows tall and only 8 columns wide, which is impractical for long word lines and bit lines. Folding the array toward a square shape shortens both.

34-8

≈ 212† rows · ≈ 211† columns

Expansion note: why 12 and 11

The row and column counts multiply to 223 bits, so the exponents add to 23. A square array would have 211.5 on each side; the nearest powers of two are 212×211. The exact split is a design choice.

Q. How do we access a particular bit?

Bit Line · Word Line · 12†-bit Row decoder · 11†-bit Column decoder

(*) To minimize area†, we implement the storage cell† using our CMOS† transistors plus some peripheral circuits†

Expansion note: how an address selects one bit

The row decoder turns an M-bit row address into one active word line out of 2M. The column decoder picks one column out of 2N from the N-bit column address. The cell at the crossing of the active word line and the selected bit line is the one read or written.

Expansion note: the six transistors of the cell

The cell proper is P1, N1, P2, N2 (the latch) and the access transistors A1 and A2: six in all, which is why this is called the 6T SRAM cell. The word line W gates both access transistors. The sense amplifier and pre-charge circuit are shared by every cell in the column and are not counted in the 6T.

Appendix

A. Problem Types in This Notetaker and How to Solve Them

A1. Minimum width of the set pulse

Recognize it

A latch with set/reset pass transistors of known W/L, a node capacitance, and the question "how long must S and φ stay high?" (pp. 34-2 to 34-6).

Method

  1. Find (W/L)NP12=12(W/L)NP1.
  2. At t=0 (VQ‾=VDD): NP12 is in saturation, P1 is off. iC(0)=12Kn′(W/L)NP12(VDD−Vtn)2.
  3. At tPHL (VQ‾=VDD/2): both are in triode. iC(tPHL)=iDNP12−iDP1 with the triode equation.
  4. Average: iC,ave=12[iC(0)+iC(tPHL)] and tPHL=CVDD/(2iC,ave).
  5. For Q rising to VDD/2 use ap=2/[74−3|Vtp|/VDD+(|Vtp|/VDD)2] and tPLH=apC/(Kp′(W/L)pVDD).
  6. Tmin=tPHL+tPLH.

Checks

  • For the 65 nm example with C=10 fF: 380.3, 180 and 280.1μA; tPHL=17.85 ps, tPLH=27.02 ps, Tmin=44.9 ps.

Common mistakes

  • Using the saturation equation at VDD/2 (the transistors are in triode there).
  • Using VDD instead of VDD/2 for the voltage change in tPHL.
  • Leaving out tPLH.

Worked in these notes: pp. 34-3 to 34-6.

A2. Organizing a memory of a given size

Recognize it

"How do we architect 1 MB of memory?" (pp. 34-7, 34-8).

Method

  1. Convert the size to bits: bytes × 8 (1 MB =220×23=223).
  2. Choose a nearly square array: rows 2M, columns 2N with M+N=23.
  3. Rows are chosen by the M-bit row decoder (word lines) and columns by the N-bit column decoder (bit lines).

Checks

  • 2M×2N must equal the bit count.

Common mistakes

  • Forgetting the 8 bits per byte.

Worked in these notes: pp. 34-7, 34-8.
