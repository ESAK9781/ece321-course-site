Expansion note: why complementary MOS is useful

In a CMOS logic gate, the PMOS network pulls the output high and the NMOS network pulls it low. In a stable logic state, one network is off, so the ideal gate draws almost no static current.

Appendix

Part A: Problem-solving patterns

Classify an NMOS operating region

Use the gate-source and drain-source voltages: cutoff when VGS ≤ Vtn; triode when VGS > Vtn and VDS < VGS − Vtn; saturation when VGS > Vtn and VDS ≥ VGS − Vtn.

Find the small-signal output resistance of a saturated NMOS

Find the DC drain current, then use ro ≈ 1/(λID) = VA/ID. The ideal λ = 0 model predicts infinite output resistance; a real or specified model needs a nonzero λ.

Choose a drain resistor for a specified drain voltage

First find the region and solve the appropriate MOSFET current equation. Then apply KCL at the drain: RD = (VDD − VD)/ID. Finally verify the assumed region using the resulting terminal voltages.

Set up a MOSFET simulation model

Select the device model, enter VTO, KP, channel dimensions and LAMBDA, then inspect the DC operating point. Compare VGS, VDS and ID with the hand model; the packet does not supply numeric Multisim settings.
