Expansion note: what the tangent at the Q-point represents

The curved diode I–V relation can be approximated locally by its tangent around a steady operating point. Its slope is diD/dvD=1/rd, so a smaller rd means current changes more for the same small voltage change. The tangent is reliable only near that bias point.

A. Problem Types in This Notetaker and How to Solve Them

A1. Find a diode's small-signal resistance

Recognize it: A forward-biased diode has a stated or computed DC current and the question asks for its incremental model.

Method:

  1. Find the DC operating current using the large-signal circuit.
  2. Choose VT and ideality factor n; use rd=nVT/ID (the packet's numerical example assumes n=1).
  3. Add any specified series resistance rs to the incremental model.
  4. Check that the signal excursion is small compared with the thermal-voltage scale.

Common mistakes: Use the signal current instead of the DC bias current, or apply the local linear model to a large voltage swing. Worked in these notes: p. 6-4.

A2. Estimate line regulation with a diode string

Recognize it: A small source variation is applied while the diode string remains conducting.

Method:

  1. Find the DC bias, approximately Vo≈NVF and ID=(Vin−Vo)/R for an unloaded output.
  2. Compute string resistance Nrd=NnVT/ID.
  3. For an unloaded output, ΔVo/ΔVi=Nrd/(R+Nrd). For a load, replace Nrd by Nrd∥RL.
  4. Multiply by the actual input change if an output change in volts is requested.
  5. Check that the diodes remain forward conducting after the perturbation.

Common mistakes: Forget the number of series diodes or use the unloaded formula after attaching a load. Worked in these notes: pp. 6-3–6-6.

A3. Analyze a loaded diode regulator

Recognize it: A load resistor is attached across the diode string.

Method:

  1. Use the DC circuit to estimate Vo and the series current.
  2. Find Iout=Vo/RL and subtract it from the resistor current to get ID.
  3. Calculate each diode's rd=nVT/ID.
  4. Compute the output small-signal load Nrd∥RL.
  5. Use voltage division with the source resistor to find line regulation; verify ID>0 and enough forward bias remains.

Common mistakes: Treat load current as diode current, or omit the parallel load in the AC model. Worked in these notes: pp. 6-5–6-6.

A4. Linearize a Zener diode and find its regulated output

Recognize it: The source, series resistor, and local Zener parameters VZ0 and rz are given.

Method:

  1. Use the local model VZ=VZ0+rzIZ.
  2. Apply KVL: VS=RIZ+VZ.
  3. Solve IZ=(VS−VZ0)/(R+rz).
  4. Substitute to obtain Vo=VZ=VZ0+rzIZ.
  5. Check the computed current falls inside the Zener's specified operating range and power limit; no such limits are supplied in this example.

Common mistakes: Use a forward-diode drop, reverse the voltage polarity, or use rz as if it were the full Zener voltage. Worked in these notes: pp. 6-7–6-8.

A5. Measure line regulation from a transient simulation

Recognize it: The input has a small periodic variation about a DC operating level, and the output waveform is to be measured.

Method:

  1. Set the model and source values from the lab instructions.
  2. Run a transient analysis long enough to include steady cycles, with a maximum timestep small enough to resolve the waveform.
  3. Use cursors to compare corresponding peak/trough values and find ΔVin and ΔVout.
  4. Compute LR=ΔVout/ΔVin, reporting V/V or percent.
  5. Repeat for the assigned series-resistor settings and compare while checking that the diode current remains in regulation.

Common mistakes: Compare peak-to-peak input against a one-sided output change, include startup transient values, or report a ratio without units/convention. Worked in these notes: pp. 6-8–6-10; numeric simulation results and lab limits are absent.

C. Equations Used Throughout

C1. Diode small-signal model

Incremental resistance (ideality factor n): rd=nVT/ID.

First-order exponential expansion: ex≈1+x for |x|≪1.

Optional series resistance: rd,total=rs+rd.

C2. Forward diode-string regulator

Approximate output: Vo≈NVF while all N junctions conduct.

Unloaded line regulation: LR=ΔVo/ΔVi=Nrd/(R+Nrd).

Loaded output incremental resistance: Ro=Nrd∥RL.

Loaded line regulation: LR=Ro/(R+Ro).

Current split: ID=(Vin−Vo)/R−Iout and Iout=Vo/RL.

C3. Local Zener model

VZ=VZ0+rzIZ.

IZ=(VS−VZ0)/(R+rz).

Vo=VZ0+rzIZ.

C4. Waveform measurement

LR=ΔVout/ΔVin in V/V; multiply by 100 to express percent.
