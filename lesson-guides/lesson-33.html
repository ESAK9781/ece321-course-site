(*) We now transition from combinational circuits where the output only depends on present inputs to sequential circuits where the output depends on present inputs and previous states

Expansion note: combinational versus sequential circuits

A logic gate has no memory: change its inputs and the output follows, so a table of inputs and outputs describes it completely. A latch keeps a stored value, so the same inputs can give two different outputs depending on what was stored before. The extra column in the SR tables on the next pages, Qn or Qn+1, records that earlier state.

(*) To start, let's review the difference between a

  • Latch: responds continuously† to input† changes and is level† sensitive
  • Flip-Flop: responds only at active edge† of clock† → edge† triggered
Expansion note: level-sensitive versus edge-triggered

A latch is transparent while its enable is active, so any input change during that time reaches the output. A flip-flop samples its inputs only at the instant the clock changes (the active edge) and ignores them the rest of the time. The same cross-coupled storage cell sits inside both.

(*) Recall if one input of an OR is 1 the output is 1; if both are 0 the output is 0. (The NOR output is the opposite.)

  • S=1 ② OR → 1 → NOR2 = 0
    R=0 ① OR → 0 → NOR1 = 1
  • S=0 ① OR → 0 → NOR1 = 1
    R=1 ② OR → 1 → NOR2 = 0
  • S=0 ② OR → Qn → NOR2 = Q‾n
    R=0 ① OR → Q‾n → NOR1 = Qn
  • S=1 ① OR → 1 → NOR1 = 0
    R=1 ② OR → 1 → NOR2 = 0
Expansion note: how to read the four lines

NOR1 produces Q from R and Q‾; NOR2 produces Q‾ from S and Q. The first line is the set case: S=1 forces Q‾=0, and then NOR1 sees R=0 and Q‾=0 so Q=1. The second line is reset by the same logic. In the third line both inputs are 0, so each gate just inverts the other's output and the pair holds whatever it had, which is what the table's Qn means. In the last line both outputs are forced to 0, which breaks the rule that Q and Q‾ are complements; if R and S then drop to 0 together the final state is unpredictable, so this input is not used.

(*) Each 2-input NOR gate requires 4 transistors so this SR-latch requires 8

  • S=1 S‾= 0 ① AND = 0 → NAND1 = 1
    R=1 R‾= 0 ② AND = 0 → NAND2 = 1
Expansion note: why the NAND latch needs complemented inputs

A NAND gate acts on a 0, not a 1: any 0 on an input forces its output to 1. So the latch is set or reset by pulling an input low. To keep the same truth table as the NOR latch, the inputs are written as S‾ and R‾, the complements of the logical S and R. Here NAND2 takes S‾ and makes Q, and NAND1 takes R‾ and makes Q‾. In the table's last row both NAND inputs S‾ and R‾ are 0, so both outputs are 1 and the complement rule fails; that row is not used.

(*) Each 2-input NAND gate requires 4 transistors so this SR-latch requires 8 (more unless logic upstream)

Cross-Coupled Inverter† Bi-stable† Circuit

so functionally we have

When W= 0 → X= 1 → Y= 1 → Z= 0
W= 1 → X= 0 → Y= 0 → Z= 1

Expansion note: why W = Z closes the loop consistently

In the circuit X is wired to Y and Z is wired back to W. Start with W=0: inverter 1 makes X=1, so Y=1 and inverter 2 makes Z=0. That returns 0 to W, which is what we assumed, so the state is self-consistent and can last indefinitely. The same holds starting from W=1. Each inverter reinforces the other, which is the positive feedback of a latch. The two inverters use four transistors, half of the eight of the NOR or NAND latch.

33-5

(*) We can visualize the stable† and unstable† points two ways. First, the cascade of two inverter transfer curves† (loop broken) superimposed with the requirement that V_Z =V_W

Expansion note: reading the cascade plot

With the loop broken, VW drives inverter 1 and inverter 2 produces VZ, so the curve is two inverter transfer curves in series: it stays near 0 until VW passes about VDD/2, then jumps to VDD. Closing the loop forces VZ=VW, the straight line of unit slope. The loop can only sit where the curve and the line intersect: points A (0), B (VDD/2) and C (VDD).

(*) So, we see we have a metastable† operating point which is unstable. Any perturbation† away from VDD/2 moves it in that direction to either 0 or VDD

(*) This circuit is said to be bistable† → two† stable operating points and one unstable point† and stores one bit of information

Expansion note: why the middle point is unstable

At B the curve is much steeper than the unit-slope line, so the loop gain is far above 1. A tiny rise in VW comes back around the loop larger than it started, and the signal grows until it reaches the flat part of the curve at C. A tiny fall does the same toward A. At A and C the curve is nearly flat, the loop gain is below 1, and any small disturbance dies out.

(*) Next, we need to incorporate inputs†: S†, R†, and an enable (clock)†. We will use what are called pass† transistors: transistors in series† to realize a logical AND†. For instance

Y= B·C†

which suffers from threshold† voltage drop† if we try and pull up† but will work fine with NMOS† to pull down†. Let's see how this works†

Expansion note: why an NMOS pass transistor is good at pulling down but not up

An NMOS conducts only while its gate is at least Vtn above its source. Passing a 0 keeps the source at 0 V, so the gate-source voltage stays large and the transistor stays on all the way. Passing a 1 raises the source until VGS falls to Vtn, so the output tops out about one threshold below the gate level, near VDD−Vtn. For a latch this is acceptable: we only need the pass transistors to pull a node down toward 0 to start the switching.

Expansion note: why the pass transistors have to win the tug of war

While Q‾ is high, P1 is on and pushes current into node Q‾ to hold it there. The series pair NP1, NP2 (gated by φ and S) pulls the same node toward ground. Node Q‾ only moves down if the pull-down current at least equals the pull-up current while VQ‾ is still around VDD/2. Once it falls below the switching threshold of the (P1,N1) inverter, that inverter's output rises, which feeds the other inverter and finishes the change on its own. The pass transistors therefore need only start the switch, not complete it.

Expansion note: why two series transistors become one at half the W/L

Two identical transistors in series with equal gate drive carry the same current as one transistor with twice the length, which is a single transistor of half the W/L. Here NP1 and NP2 are both fully on during the write (φ=S=VDD), so NP12 has VDD on its gate and (W/L)NP12=12(W/L)NP1. On the other side R=0 keeps NP4 off, so NP34 is drawn with its gate at 0 and carries no current.

The minimum (W/L)=4 (W=260 nm) makes the pull-down exactly equal to the pull-up at VDD/2, so any variation in the process or in the voltages could leave the latch stuck. Appendix

A. Problem Types in This Notetaker and How to Solve Them

A1. Finding the next state of an SR latch (NOR or NAND)

Recognize it

You are given R and S and asked for Qn+1 and Q‾ (pp. 33-2, 33-3).

Method

  1. Write each gate's equation: NOR latch Q=R+Q‾‾, Q‾=S+Q‾; NAND latch Q=S‾Q‾‾, Q‾=R‾Q‾.
  2. Look for the input that forces an output: a 1 into a NOR gives 0; a 0 into a NAND gives 1.
  3. Pass that forced output to the other gate and evaluate it.
  4. If neither input forces anything (both inputs inactive), the latch holds Qn.

Checks

  • Q and Q‾ must be complements, except in the unused row.

Common mistakes

  • Mixing up active-high (NOR) and active-low (NAND) inputs.
  • Treating the unused row (S=R=1 for NOR, S‾=R‾=0 for NAND) as a valid state.

Worked in these notes: pp. 33-2 and 33-3.

A2. Finding the stable and unstable operating points of cross-coupled inverters

Recognize it

Two inverters with the output of each tied to the input of the other; asked how many states it has or what it stores (pp. 33-4 to 33-6).

Method

  1. Break the loop at one inverter input and plot the cascade of the two transfer curves.
  2. Draw the line VZ=VW for the closed loop.
  3. Each crossing is an operating point.
  4. Check the loop gain at each: slope above 1 (the middle crossing) means unstable; slope near 0 (the outer crossings) means stable.

Checks

  • A matched pair crosses at 0, VDD/2 and VDD, with VM=VDD/2 the unstable point.

Common mistakes

  • Counting the middle point as a place the latch can stay; noise always pushes it to one end.

Worked in these notes: pp. 33-5 and 33-6.

A3. Sizing the set/reset pass transistors so the latch will switch

Recognize it

A cross-coupled latch with series NMOS pass transistors (gates φ and S) pulling node Q‾ down; you must find the minimum (W/L) of those transistors (pp. 33-7 to 33-11).

Method

  1. Replace the series pair with one transistor, (W/L)NP12=12(W/L)NP1.
  2. Evaluate both transistors at VQ‾=VDD/2: check each is in triode (VDS<VOV).
  3. Write IDNP12=μnCox(W/L)NP12[VOVVDS−12VDS2] and IDP1 the same way with μp.
  4. Require IDNP12≥IDP1 and solve for (W/L)NP1.
  5. Multiply by the safety factor 2 and convert to a width with W=(W/L)L.

Checks

  • For VDD=1.0 V, Vtn=|Vtp|=0.35 V, μn=3μp and (W/L)p=6 the result is (W/L)NP1=4 minimum, 520 nm after doubling.

Common mistakes

  • Forgetting the factor of 12 for the series pair.
  • Using the saturation equation: at VDD/2 both devices are in triode.

Worked in these notes: pp. 33-8 to 33-11.
