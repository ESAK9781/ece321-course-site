Basic Definitions

Passive Sign Convention & Kirchhoff's Laws

Passive Sign Convention

If current IX flows into the terminal marked with the positive voltage reference VX:

PX=VX·IX(Power absorbed by Component X)

If PX > 0, power is absorbed; if PX < 0, power is delivered.

Kirchhoff's Laws

KVL (Voltage Law): Sum of voltages around any closed loop is zero:

∑LoopV=0

KCL (Current Law): Sum of currents entering any circuit node is zero:

∑NodeI=0

3. Circuit Analysis Techniques & Network Theorems

Nodal & Mesh Analysis

Nodal Analysis (KCL)
Iout X=VX−VYRXY

Write KCL at each non-reference essential node; express branch currents in terms of node voltages.

Mesh Analysis (KVL)
V12=(I1−I2)·R12

Write KVL around each independent planar mesh loop; express voltage drops in terms of circulating mesh currents.

Source Transformation & Superposition

Source Transformation

A real voltage source (VS in series with RS) is fully equivalent to a real current source (IS in parallel with RS):

IS=VSRSVS=IS·RS
Superposition Theorem

In any linear resistive network with multiple independent sources:

VX=VX,S1 on+VX,S2 on+VX,S3 on+…

Deactivate other independent sources: replace independent voltage sources with short circuits (0 V) and independent current sources with open circuits (0 A). Never turn off dependent sources!

4. Thevenin Equivalent & Maximum Power Transfer

Thevenin / Norton Equivalence

  1. Open-Circuit Voltage (VTH): Disconnect network B at terminals m and n. Keep all internal sources in Network A active and find open-circuit terminal voltage:
    VTH = VOC
  2. Short-Circuit Current (ISC): Short terminals m and n together with sources in A active:
    IN = ISC
  3. Thevenin Resistance (RTH):
    RTH=VOCISC
    Alternative (independent sources only): Turn OFF all independent sources in Network A and compute look-back resistance across terminals m and n.

Maximum Power Transfer Theorem

Matching Condition

To transfer maximum power from a linear network with Thevenin resistance RTH into a variable load resistor RLoad, choose:

RLoad=RTH=Rout
Maximum Absorbed Load Power
PLoad,max=VTH24RTH

At maximum power transfer, efficiency is 50% (half of total power is dissipated internally inside RTH).
