1. Amplifier Behavioral Model & Voltage Gains Lesson 15

Three-Parameter Behavioral Model

Any linear amplifier stage is characterized by three core parameters:

  • Input Resistance (Ri): Look-in resistance seen by the source.
  • Output Resistance (Ro): Look-back resistance seen by the load with independent input sources killed.
  • Open-Circuit Voltage Gain (Avo): Gain vo / vi when load is disconnected (RL = ∞).

Voltage Gain Definitions

Loaded Voltage Gain (Av)
Av=vovi=Avo·RLRo+RL
Overall Voltage Gain (Gv)
Gv=vovs=RiRs+Ri·Avo·RLRo+RL

2. Common-Source (CS) Amplifier Voltage Transfer Curve (VTC) Lesson 15

Critical Boundary Points on the VTC

PointRegionConditions
Point A Cutoff Boundary vGS=Vt,vDS=VDD (FET turns ON)
Point B Triode Boundary (Max Gain) VDS,B=Vov,B=1+2KnRDVDD−1KnRD
Point C Deep Triode vDS≈0 V (Drain voltage drops near 0 V)

To achieve linear amplification without clipping, the operating point Q must be placed in Saturation (between Points A and B).

Small-Signal Gain Derivation from VTC
vD=VDD−RD·[12Kn(vGS−Vt)2]
Avo=dvDSdvGS|Q=−KnRDVov=−gmRD

The negative sign indicates a 180° phase inversion between gate input and drain output.

3. CS-Amplifier Design Procedure (No Source Resistance RS) Lesson 17

  1. Choose DC Drain Voltage: Set VDS=VDD2 to center drain voltage between VDD and ground for symmetric signal swing.
  2. Compute Overdrive Voltage: Vov=2(VDD−VDS)|Avo|=VDD|Avo| Check: Ensure Vov is large enough to maintain linearity (vgs,pk≤0.2Vov).
  3. Compute Drain Resistance (RD): RD=|Avo|·VovKn·Vov2=VDD−VDSID
  4. Compute Gate Bias Voltage: VG=VGS=Vov+Vt (since VS = 0 V).
  5. Compute Gate Bias Resistors (RG1, RG2): RG1≥VDDVGRinRG2=RG1VDDVG−1

4. CS-Amplifier Design Procedure (Fully AC-Bypassed RS) Lesson 18

Adding source resistor RS stabilizes the DC operating point against variations in Kn and Vt. AC-bypassing RS with capacitor Cby preserves high small-signal gain (|Avo|=gmRD).

  1. Allocate Branch Voltages (Equal Thirds): VRD=VDS=VRS=VDD3
  2. Compute DC Drain Current (ID): ID=2Kn[|Avo|23VDD]2=9|Avo|22KnVDD2
  3. Compute Drain & Source Resistors: RD=RS=VDD/3ID
  4. Compute Overdrive Voltage: Vov=2IDKnVGS=Vov+Vt,VG=VGS+VDD3

5. CS-Amplifier Design (Partially AC-Bypassed RS) Lesson 18–19

Source degeneration resistance RS1 improves linearity and stabilizes voltage gain against Kn variations, while RS2 is AC-bypassed.

  1. Bias Allocation: Set VRD=VDS=VRS=VDD3. Choose degeneration condition RS1 = 1 / gm.
  2. Compute Drain Current (ID): With RS1 = 1/gm, gain is halved (|Avo|=gmRD2): ID=2Kn[6|Avo|VDD]2
  3. Find RD and Total RS: RD=RS=VDD/3ID.
  4. Compute Overdrive: Vov=2IDKn.
  5. Compute Transconductance & Split RS: gm=KnVov, then RS1=1gm and RS2=RS−RS1.
  6. Compute Gate Bias: VGS=Vov+Vt,  VG=VGS+VS=VGS+VDD3.
  7. Compute Gate Divider (RG1, RG2): RG1≥VDDVGRin, RG2=RG1VDDVG−1.
  8. Headroom and Legroom Check: vd,pk=|Avo|·vg,pk, verify VD,max=VD+vd,pk≤VDD and VD,min=VD−vd,pk≥VS+Vov.
  9. Linearity Check: vgs,pk=vg,pk1+gmRS1≤0.2Vov.

6. Common-Drain (CD) Source-Follower Amplifier Design Lesson 19–20

CD Behavioral Parameters

Input Resistance RiRG1 ∥ RG2 (Very high)
Output Resistance RoRS∥1gm≈1gm (Low, drives heavy loads)
Open-Circuit Gain AvoRSRS+1/gm=gmRS1+gmRS≈1

CD 11-Step Design Workflow

  1. Assume VLoad,pp/Vin,pp≈0.85 for preliminary sizing.
  2. Pick VS≈12VDD.
  3. Find peak load current: ILoad,pk=VLoad,pp/2RLoad.
  4. Choose minimum drain current ID,min (ensures FET never cuts off).
  5. Find max source resistor current: IRS,max=ID,min+ILoad,pk.
  6. Find minimum voltage across RS: VRS,min=VS−VLoad,pp2.
  7. Calculate RS: RS=VRS,min/IRS,max.
  8. Find quiescent current: ID=VS/RS.
  9. Compute Vov=2ID/Kn.
  10. Find gate voltage: VG=VS+Vov+Vt.
  11. Size gate bias divider: RG1≥VDDVGRin, RG2=RG1VDDVG−1.

8. Measuring Small-Signal Parameters & Power Calculations Laboratory Procedures

Laboratory Measurement Procedures

Measuring Input Resistance (Ri)

Potentiometer method: Place potentiometer Rpot in series with input signal generator. Adjust until amplifier input voltage drops to half source generator voltage: V2,pp=0.5V1,pp. Then Ri = Rpot.

Test resistor method: Insert known Rtest in series with input. Ri=Rtest·V2,ppV1,pp−V2,pp.

Measuring Output Resistance (Ro)

Short AC signal source to ground (DC supplies remain ON). Drive output terminal through Rpot or Rtest from external signal generator. When V2,pp=0.5V1,pp, Ro = Rpot.

Measuring Avo and Av

Avo: Disconnect load (open circuit). Avo=Vout,pp/Vin,pp.

Av: Connect specified load resistance RL. Av=Vout,pp/Vin,pp.

Power Dissipation Calculations

DC Losses

MOSFET: Pdiss,DC=VDS·ID

Resistor: Pdiss,DC=VR2R=IR2·R

AC Losses (Sinusoidal Signals)

Resistor: Vrms=Vpp/22=Vpk2Pdiss,AC=Vrms2R

MOSFET: Pdiss,AC=12vds,pk·ids,pk

9. Bipolar Junction Transistor (BJT) Fundamentals & Biasing Lesson 25

Active Mode Governing Equations

iC=βiBiC=αiEα=ββ+1
IC=ISeVBE/VTiE=iB+iC=(β+1)iB

For silicon BJT in active mode, standard assumption is VBE = 0.65 V to 0.7 V.

Small-Signal Hybrid-π Model
gm=ICVTrπ=βgm=βVTICro=VAIC

BJT Biasing Design Procedure

Given IC, β, VCC, and VBE = 0.65 V:

  1. Allocate voltages: VRC=VCE=0.4VCC  and  VRE=0.2VCC.
  2. Compute base current: IB=IC/β.
  3. Choose divider bleed current: IRB1 = 50 · IB (ensures stiff base voltage).
  4. Compute collector and emitter resistors: RC=VRCIC,RE=VREIC+IB.
  5. Compute base voltage: VRB2=VB=VBE+VRE.
  6. Compute lower bleed current: IRB2=IRB1−IB.
  7. Compute lower base resistor: RB2=VRB2/IRB2.
  8. Compute upper base resistor: RB1=(VCC−VRB2)/IRB1.
