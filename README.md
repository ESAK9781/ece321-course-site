# ECE 321 study website

Open `index.html` in a browser. This is a static, responsive site with no build step or external dependencies. The course pages, guide library, and study-session shell work offline.

The site includes the Fall 2026 syllabus, published lesson and homework reading guides, GR1 and GR2 study hubs, and a reusable Study sessions view. It contains no source textbook or instructor PDF downloads.

AI settings are available from the small settings control on the page. Provider keys stay in this browser?s local storage. Without keys, core navigation, guide reading, answer reveal, and local study progress remain available; provider-dependent answer checking and clarification are disabled.

All paths are relative, so the site can be opened locally or hosted under a subdirectory.
