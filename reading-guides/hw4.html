Problem 5.5 Lesson 8 · p. 293 · §5.1

Small-v_DS operation as a MOSFET variable resistor.

Problem statement

D 5.5 An NMOS transistor fabricated in a technology for which k′n = 511 µA/V2 and Vt=0.4V is required to operate with a small vDS as a variable resistor ranging in value from 250 Ω to 1 kΩ. Specify the range required for the control voltage vGS and the required transistor width W. It is required to use the smallest possible device, as limited by the minimum channel length of this technology (Lmin=0.13\mu m) and the maximum allowed voltage of 1.3 V.

Similar to 5.5 same task, new values

Similar problem (new numbers)

An NMOS made with k′_n = 420 μA/V² and V_t = 0.45 V must act as a small-v_DS variable resistor from 300 Ω to 1.2 kΩ. Use L_min = 0.15 μm and a maximum gate voltage of 1.5 V. Find a control-voltage range and the minimum width that reaches the lower resistance at the voltage limit.

1 · Set the width from the lowest resistance

At the upper gate limit, V_OV = 1.50 − 0.45 = 1.05 V. Since r_DS = 1/(k′_n(W/L)V_OV), the required k_n is 1/(300·1.05) = 3.174 mA/V². Thus W/L = 3.174/0.420 = 7.56 and W = 7.56(0.15) = 1.13 μm.

2 · Find the other endpoint

For 1.2 kΩ with the same device, V_OV = 1/(3.174 mA/V²·1.2 kΩ) = 0.2625 V, so V_GS = 0.45 + 0.2625 = 0.713 V.

The larger resistance corresponds to the smaller overdrive and therefore the lower gate voltage.

Problem 5.10 Lesson 8 · p. 293 · §5.1

Process parameters, saturation bias, and small-v_DS resistance.

Problem statement

5.10 Consider a CMOS process for which Lmin=0.18\mu m, tox=4nm, μn=450cm^2/V\cdot s, and Vt=0.5V.

  1. Find Cox and k′n.
  2. For an NMOS transistor with W/L=2.4\mu m/0.18\mu m, calculate the values of vOV, vGS, and vDS,min needed to operate the transistor in the saturation region with a current iD=0.1mA.
  3. For the device in (b), find the values of vOV and vGS required to cause the device to operate as a 500-Ω resistor for very small vDS.

Similar to 5.10 same task, new values

Similar problem (new numbers)

A CMOS process has L_min = 0.22 μm, t_ox = 5 nm, μ_n = 380 cm²/(V·s), and V_t = 0.45 V. For W/L = 3.0 μm/0.22 μm, find C_ox and k′_n, then the overdrive, gate voltage, and minimum saturation voltage at I_D = 0.08 mA. For the same device, find the gate voltage for a 750-Ω small-v_DS resistance.

1 · Process capacitance and parameter

Using ε_ox = 3.9ε_0, C_ox = 3.9(8.854×10⁻¹²)/(5×10⁻⁹) = 6.906×10⁻³ F/m² = 6.906 fF/μm². With μ_n = 0.038 m²/(V·s), k′_n = μ_nC_ox = 2.624×10⁻⁴ A/V² = 262.4 μA/V².

2 · Saturation bias

k_n = 262.4 μA/V² × (3.0/0.22) = 3.578 mA/V². From I_D = ½k_nV_OV², V_OV = √(2·0.08/3.578) = 0.2115 V. Thus V_GS = 0.6615 V and V_DS,min = V_OV = 0.2115 V.

3 · Small-signal resistance

For r_DS = 750 Ω, V_OV = 1/(k_n r_DS) = 1/[3.578 mA/V²·750 Ω] = 0.3726 V. Then V_GS = V_t + V_OV = 0.8226 V.

Problem 5.13 Lesson 8 · p. 294 · §5.1

Small-v_DS switch resistance and NMOS/PMOS conductance comparison.

Problem statement

5.13 An n-channel device has k′n=400 µA/V2, Vt=0.5V, and W/L=20. The device is to operate as a switch for small vDS, utilizing a control voltage vGS in the range 0 V to 1.8 V. Find the switch closure resistance, rDS, and closure voltage, vDS, obtained when vGS=1.8V and iD=0.2mA. If μp=0.25μn, what must W/L be for a p-channel device that provides the same performance as the n-channel device in this application?

Similar to 5.13 same task, new values

Similar problem (new numbers)

An NMOS has k′_n = 360 μA/V², V_t = 0.45 V, and W/L = 16. It is used as a small-v_DS switch with V_GS up to 1.6 V. Find its closure resistance and the drain-to-source voltage at I_D = 0.15 mA. If μ_p = 0.30μ_n, find the PMOS W/L for equal closure resistance.

1 · Device parameter and closure resistance

k_n = 360 μA/V² × 16 = 5.76 mA/V², and the maximum overdrive is 1.6 − 0.45 = 1.15 V. Thus r_DS = 1/(5.76 mA/V² × 1.15 V) = 151 Ω.

2 · Small drain voltage at the stated current

In the small-v_DS region, v_DS ≈ i_Dr_DS = 0.15 mA × 151 Ω = 22.6 mV.

3 · Match with a PMOS

Equal resistance requires equal k′(W/L)V_OV. With matched overdrive and k′_p = 0.30k′_n, the PMOS aspect ratio is (W/L)_p = (W/L)_n/0.30 = 53.3.

Summarized · pp. 251–253, 259–260

At very small drain voltage, the channel conductance is proportional to process transconductance, W/L, and overdrive. Reading · 5.26

Summarized · pp. 261–263

First convert terminal voltages to source-referenced quantities. If the drain-source difference is negative, the textbook treats the device symmetrically by exchanging the drain and source labels before using the NMOS region conditions. A gate-source voltage below threshold gives cutoff. Above threshold, compare the drain-source voltage with overdrive to distinguish a continuous channel from pinch-off.

Quoted · Table 5.1, p. 263

“v_DS < v_OV” defines the triode side of the boundary; “v_DS ≥ v_OV” defines the saturation side.

Expansion note: Why use terminal differences?

Ground-referenced node voltages can all be positive or negative. MOSFET operation depends on the voltage between particular terminals, so subtract the source voltage before applying a region condition.

Problem 5.40 Lesson 9 · p. 297 · §5.2

PMOS cutoff, saturation, and triode boundaries during a gate-voltage sweep.

Problem statement

5.40 The PMOS transistor in Fig. P5.40 has Vtp=−0.4V. As the gate voltage vG is varied from +2 V to 0 V, the transistor moves through all of its three possible modes of operation. Specify the values of vG at which the device changes modes of operation.

Similar to 5.40 same task, new values

Similar problem (new numbers)

A PMOS has V_tp = −0.6 V, source at +2.0 V, and drain at +0.5 V. As v_G moves from +2.2 V down to −0.2 V, identify the gate voltages at which the device enters conduction and changes between saturation and triode operation.

1 · Cutoff boundary

The PMOS begins conducting when V_SG=|V_tp|. Here V_S=2.0 V and |V_tp|=0.6 V, so the boundary is v_G=2.0−0.6=1.4 V.

2 · Saturation/triode boundary

V_SD=2.0−0.5=1.5 V. The boundary is V_SD=V_SG−|V_tp|, so V_SG=2.1 V and v_G=2.0−2.1=−0.1 V. The device is in saturation between the two boundaries and in triode below −0.1 V over this sweep.

Reading · 5.40

Summarized · pp. 260–263, 270–271

For PMOS devices the book uses signed terminal voltages, with a negative threshold. Region interpretation is easiest with source-referenced magnitudes: conduction starts when the source-to-gate magnitude exceeds the threshold magnitude. The triode/saturation boundary compares the source-to-drain magnitude with the PMOS overdrive magnitude. The gate sweep can therefore cross cutoff, saturation, and triode in sequence.

Expansion note: Why is the gate sweep direction reversed?

With the source held at a positive voltage, lowering the gate increases V_SG. The PMOS channel strengthens as the magnitude of source-to-gate bias grows.
