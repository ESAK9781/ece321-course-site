ECE 321: Electronics I — Syllabus

Complete 41-lesson schedule table detailing lecture topics, textbook readings (Sedra & Smith 8th ed.), practical exercises, homework problem sets, and assessment due dates.

All Course Docs
Course Overview: ECE 321 covers semiconductor physics, diode fundamentals and models, MOSFET amplifier design (CS, CD, CG, multi-stage), BJT fundamentals, CMOS digital logic inverter analysis, and static RAM memory cells. Key abbreviations: PE = Practical Exercise; S&S = Sedra & Smith Microelectronic Circuits (8th ed.); SP = Special Topic Presentation; MS = Multisim computer simulation.
