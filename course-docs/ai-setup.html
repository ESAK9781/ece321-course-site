AI Setup (Optional)

What connecting an AI provider adds to the study sessions, and how to get an API key from each provider.

Why set it up Optional

What AI adds

  • Short-answer grading. Typed answers are checked for meaning, so correct reasoning in your own words counts. Without it you compare against the reference answer and rate yourself.
  • Ask a tutor. After any question, press ? to ask a follow-up and get a short explanation grounded in that question.

What works without it

  • All multiple-choice, true/false, select-all and ordering questions.
  • Adaptive review: the sessions still focus on what you miss and spread across every topic.
  • Explanations, progress tracking and the guides.

Which key for what: a decision provider (Jev or OpenAI) grades typed answers; a text provider (OpenAI, Anthropic or Gemini) powers the tutor. One OpenAI key covers both. Pick providers in the AI panel (the AI button, bottom right).

OpenAI Grades typed answers and answers tutor questions

  1. Open the OpenAI API keys page ↗ and sign in (or create an account).
  2. Add a payment method or prepaid credit under Billing. API use is pay-as-you-go and is billed separately from any ChatGPT subscription.
  3. Choose Create new secret key, give it a name such as "ECE 321 study", and copy it. OpenAI shows the key only once.
  4. Optional but wise: set a low monthly spending limit in Billing.
  5. Paste the key into the AI panel on this site (the AI button, bottom right). Keys usually start with sk-.

Anthropic Answers tutor questions

  1. Open the Anthropic Console API keys page ↗ and sign in (or create an account).
  2. Add credit under Billing. API use is pay-as-you-go and separate from a Claude subscription.
  3. Choose Create Key, name it, and copy it right away; it is not shown again.
  4. Paste the key into the AI panel on this site. Keys usually start with sk-ant-.

Gemini Answers tutor questions

  1. Open Google AI Studio, API keys ↗ and sign in with a Google account.
  2. Choose Create API key and copy it. Google offers a free tier with usage limits; paid use needs a billing account.
  3. Paste the key into the AI panel on this site. Keys usually start with AIza.

Jev Grades typed answers (decision checks)

  1. Go to typesafe.ai ↗ (the company behind Jev) and create an account.
  2. Open your account or dashboard and create an API key. Menu names can differ; follow Jev's own documentation if the layout has changed.
  3. Paste the key into the AI panel on this site, in the Jev row.

Cost & privacy Read before you paste a key

  • Where the key lives. It is saved in this browser only (local storage) and sent only to the provider you choose. It is stored unencrypted, so use your own computer, never a shared one.
  • What is sent. Only the question text, your typed answer or your follow-up question, and the reference answer for that item. Nothing else from the site.
  • Cost. Providers charge per use. Study sessions send short requests, but set a spending limit in the provider's billing page. Gemini's free tier may cover light use.
  • Treat keys like passwords. Do not share or post them. If one leaks, delete it in the provider's dashboard and create a new one.
  • Removing a key. Open the AI panel and choose Remove next to the provider.
  • Provider sites change their menus and pricing; follow their own documentation if a step does not match.
